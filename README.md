# Паттерны и принципы проектирования на C#

Учебная коллекция примеров: паттерны проектирования GoF и принципы проектирования (SOLID, DRY, KISS, YAGNI) на C#.
Каждая папка — отдельное консольное приложение. Описание паттерна (что он делает и когда его применять) находится
в комментариях в начале `Program.cs` соответствующего проекта.

## Технологии

- C# / .NET 8 (`net8.0`)
- Включены `ImplicitUsings` и `Nullable`
- Все проекты объединены в решение `DesignPatternsAndPrinciples.sln`

## Запуск

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0). Если установлен только более новый SDK,
дополнительно понадобится .NET 8 Runtime.

```bash
git clone https://github.com/KonstantinUsikov/DesignPatternsAndPrinciples.git
cd DesignPatternsAndPrinciples
dotnet run --project "2.01. Strategy"
```

`dotnet run` сам собирает выбранный проект. В именах папок есть пробелы, поэтому путь к проекту нужно брать в кавычки.

Также можно открыть `DesignPatternsAndPrinciples.sln` в Visual Studio или Rider и выбрать нужный проект запускаемым.

## Структура проектов

Папки внутри проекта названы по ролям участников паттерна: `AbstractCreator`, `ConcreteProducts`, `Invoker`,
`Receiver`, `Adaptee`, `Leaf` и т. д. По дереву файлов сразу видно, какую роль в паттерне играет каждый класс.
